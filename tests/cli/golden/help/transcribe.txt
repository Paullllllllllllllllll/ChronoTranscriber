usage: chronotranscriber transcribe --input PATH [options]

Transcribe PDFs, image folders, EPUB and MOBI files and audio recordings; resumes earlier runs
unless --force is given.

options:
  -h, --help            show this help message and exit

input:
  --input PATH          PDF, EPUB, MOBI or audio file, image folder, or a folder of these
  --type {auto,pdf,images,epub,mobi,audio}
                        input type; auto takes the PDFs, image folders, EPUB and MOBI files of the
                        input; audio needs --type audio; default: auto
  --files LIST          comma-separated names of files or folders inside the input folder; only
                        for type audio, epub, images, mobi, pdf
  --select EXPR         select items by number (1,3), range (1-5) or name search
  --all                 process every discovered item
  --recursive, --no-recursive
                        search the subfolders of the input folder; default: off; only for type
                        audio, epub, images, mobi, pdf
  --pages RANGE         pages, images or audio chunks: 5, first:5, last:5, 3-7, 3-, -7 or 1,3,5-8;
                        default: all

method:
  --method {llm,tesseract,native,whisper,audio-api}
                        transcription method; in auto mode it serves scanned PDFs and image
                        folders; EPUB and MOBI take native and audio takes whisper unless --method
                        names another; default: llm
  --searchable-pdfs {ocr,text}
                        PDFs with a text layer in auto mode: ocr transcribes them with the method,
                        text takes the text layer; default: ocr; only for type auto

output:
  --output DIR          output folder; default: beside the input
  --beside-input        write outputs beside each input
  --layout {hash,mirror}
                        output folder layout: hash (one hash-suffixed folder per item) or mirror
                        (the input folder tree); default: hash
  --formats LIST        comma-separated output formats; from txt, md; default: txt

schema, prompt and context:
  --schema NAME|PATH    transcription schema: a name found in schemas/ or a path; default:
                        markdown_transcription_schema
  --prompt PATH|default
                        system prompt file, or default (the prompt of the response format);
                        default: default
  --context TEXT|PATH|auto|none
                        transcription context: topics as text or a path to a text file (overrides
                        sidecars), auto (the item's sidecar) or none (no context); default: auto
  --fallback-context TEXT|PATH|none
                        transcription context for items without a sidecar under --context auto:
                        topics as text, a path to a text file, or none; default: none
  --context-image PATH|auto|none
                        image sent with every page: an image file, auto (the item's sidecar image)
                        or none; default: auto

model:
  --provider {openai,anthropic,google,openrouter,custom}
                        model provider; default: inferred from the model name
  --model NAME          model name; a provider: prefix (anthropic:NAME) selects the provider;
                        default: gpt-6-luna; gpt-transcribe for --method audio-api,
                        gemini-3.6-flash with --provider google
  --endpoint NAME       named custom endpoint from the settings (implies provider custom);
                        default: none
  --reasoning-effort {none,minimal,low,medium,high,xhigh,max}
                        reasoning effort; default: xhigh
  --verbosity {low,medium,high}
                        output verbosity; default: medium
  --max-output-tokens N
                        maximum output tokens; default: the model's output limit
  --temperature T       sampling temperature, 0.0 to 2.0; default: 1.0
  --top-p P             nucleus sampling, 0.0 to 1.0; sent only when supported; default: 1.0
  --service-tier {auto,default,flex,priority}
                        OpenAI service tier; default: default; only for provider openai
  --response-format {schema,json,text}
                        schema (API-enforced), json (prompted, validated) or text (plain);
                        default: schema when the model supports it, else json

images:
  --dpi native|N        render resolution: native or a DPI value; default: the provider's
                        recommended value
  --image-detail {low,high,auto,original}
                        image detail sent to the model; default: the provider's recommended value
  --image-format {jpeg,png}
                        page image format; default: the provider's recommended value
  --jpeg-quality N      JPEG quality, 1 to 100; default: the provider's recommended value
  --grayscale, --no-grayscale
                        convert page images to grayscale; default: the provider's recommended
                        value

Tesseract:
  --ocr-config STR      Tesseract configuration string; default: --oem 3 --psm 6; only for method
                        tesseract
  --ocr-preprocess {default,sauvola,none}
                        Tesseract image preprocessing preset; default: default; only for method
                        tesseract

audio:
  --whisper-model SIZE  faster-whisper model size; default: large-v3; only for method whisper
  --language CODE|auto  spoken language as an ISO 639-1 code, or auto; default: auto; only for
                        method audio-api, whisper
  --audio-chunk-seconds N
                        length of the audio chunks sent per request, in seconds; default: 600;
                        only for method audio-api, whisper

run control:
  --batch, --no-batch   submit the pages to the provider's batch API; default: off; only for
                        method llm
  --sync-fallback, --no-sync-fallback
                        transcribe synchronously when a batch submission fails; default: off; only
                        for method llm
  --retry-errors, --no-retry-errors
                        on resume, transcribe pages again whose earlier result is an error;
                        --no-retry-errors keeps those results; default: on
  --force               transcribe items again from the start: every stored unit of the item is
                        reset, also outside --pages; stored responses are kept
  --concurrency N       parallel requests; default: 16
  --keep-working-files, --no-keep-working-files
                        keep Tesseract's preprocessed page images and the audio chunks in the
                        item's working folder; default: off
  --dry-run             plan without API calls or writes
  --json                print one JSON summary line on stdout
  --settings FILE       alternate settings file; default: config/settings.yaml

Precedence: a flag wins over the settings defaults: block, which wins over the code default.
--settings FILE reads another settings file instead of config/settings.yaml.

Exit codes:
  0    every item completed or, under --batch, was submitted, or nothing
       was left to do; a dry run that planned, also without API keys
  1    an item failed, or another run leases one (a killed run keeps its
       lease until it expires)
  2    usage or configuration error: no item found, several items without
       --all, --select or --files, --select matching nothing, a database
       the store refuses, or an unset API key variable
  130  interrupted (Ctrl+C or Ctrl+Break)

With --json, stdout carries exactly one JSON summary line on every exit; progress, warnings and
errors go to stderr.

Examples:
  Transcribe one PDF with the default vision model:
    chronotranscriber transcribe --input book.pdf --output out
  Every item of a folder, the method chosen per file:
    chronotranscriber transcribe --input scans --type auto --all --output out
  Items 1 to 3 of a folder, and those whose name holds "ledger":
    chronotranscriber transcribe --input scans --select 1-3 --output out
    chronotranscriber transcribe --input scans --select ledger --output out
  Tesseract on an image folder, Markdown output:
    chronotranscriber transcribe --input pages --type images --method tesseract
      --formats md
  Plan a run without API calls and print the summary as JSON:
    chronotranscriber transcribe --input scans --all --dry-run --json
