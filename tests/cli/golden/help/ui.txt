usage: chronotranscriber ui [-h] [--settings FILE]

Guided run: choose a task (a new transcription, a repair, batch check or cancel, render or drop),
answer its steps with Back navigation, then review the values, marked where they come from the
settings defaults, with the equivalent command, and run it, copy the command or quit. Needs an
interactive terminal.

options:
  -h, --help       show this help message and exit

run control:
  --settings FILE  alternate settings file; default: config/settings.yaml

Exit codes are those of the chosen task's command. For scripts and agents, use 'chronotranscriber
transcribe' and the other commands with flags.
